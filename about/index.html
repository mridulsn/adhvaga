About

Built to make complex journeys easier to manage.

Adhvaga explores how AI-assisted workflows can help travellers plan connected journeys, understand disruptions, and review changes without handing over control of important decisions.

It brings together transport information, rule-based validation, document retrieval, itinerary dependencies, and human approval in one travel workspace.

How it was built

Frontend

A responsive website built with TanStack Start, React, and Tailwind CSS, prerendered to static pages and hosted on GitHub Pages.

MCP servers

The Metro, Buses, and Knowledge servers run live on Vercel. The Trip server is built and runs in tests. Flights, a Trains server, the AI agent, and a Postgres store are planned.

Rules and evaluation

Hard constraints are plain application logic. A test runner checks the workflow against 100 written cases; the results appear in the Project Lab.

This preview

This site is a sample. It runs on a fixed Delhi-to-Jaipur journey so you can see the full workflow without any live keys or a backend connected.
