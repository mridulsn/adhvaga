About

A smarter way to turn travel ideas into real plans.

Adhvaga explores how AI can help travellers discover destinations, choose experiences and organise realistic itineraries - without handing over control of the decisions that matter.

It combines destination information, your preferences, grouping by area, scheduling rules and your own edits in one planning workspace. Separate transport tools plan train and metro legs and show how a plan changes when a train is cancelled.

How it was built

Trip planner

Destinations and places researched by hand, each fact with its source. A plain-code itinerary builder groups places by area, orders the route, adds meals and breaks, and explains what does not fit. Your plan is kept in your browser.

Frontend

A responsive website built with TanStack Start, React, and Tailwind CSS, prerendered to static pages and hosted on GitHub Pages.

MCP servers

The Metro, Buses, and Knowledge servers run live on Vercel. The Trip server is built and runs in tests. Flights, a Trains server, the AI agent, and a Postgres store are planned.

Rules and evaluation

Hard constraints are plain application logic. A test runner checks the workflow against 100 written cases; the results appear in the Project Lab.

This preview

This site is a sample. The trip planner works now on hand-checked destinations. The transport tools run on a fixed Delhi-to-Jaipur journey. The AI assistant is switched off until its key is connected.
