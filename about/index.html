About

A calmer way to turn a travel idea into a real plan.

Adhvaga is an India trip planner built in the open: every fact has a source, every estimate says so, and you decide what goes in.

Adhvaga helps travellers discover destinations, choose what to do there and organise realistic itineraries - without handing over control of the decisions that matter.

It combines destination information, your preferences, grouping by area, scheduling rules and your own edits in one planning workspace. A separate transport-disruption workspace, built as an engineering exercise, shows how a plan changes when a train is cancelled.

Read the engineering case study

How it was built

Trip planner

Destinations and places researched by hand, each fact with its source. A plain-code itinerary builder groups places by area, orders the route, adds meals and breaks, and explains what does not fit. Your plan is kept in your browser.

Frontend

A responsive website built with TanStack Start, React, and Tailwind CSS, prerendered to static pages and hosted on GitHub Pages.

MCP servers

The Metro, Buses, and Knowledge servers run live on Vercel. The Trip server is built and runs in tests. Flights, a Trains server, the AI agent, and a Postgres store are planned.

Rules and evaluation

Hard constraints are plain application logic. A test runner checks the workflow against 100 written cases; the results appear in the Project Lab.

This preview

This site is a sample. The trip planner works now on hand-checked destinations. The transport tools run on a fixed, simulated Delhi-to-Jaipur journey. An AI assistant is planned; nothing on this site calls one today.
