What code does, what AI does, what you do

Application code

  • Validates input
  • Enforces hard constraints
  • Does the money arithmetic
  • Checks permissions
  • Manages itinerary versions
  • Saves approved changes

AI model

  • Interprets requests
  • Extracts preferences
  • Chooses among permitted tools
  • Summarises source evidence
  • Explains trade-offs
  • Drafts proposals

You

  • Supply missing context
  • Approve or reject consequential changes
  • Make the real bookings and payments

Limitations

  • Adhvaga does not book or pay.
  • It does not cancel tickets or submit claims.
  • Some routes and cities have no verified data yet.
  • Some fares are estimates; some demo options are simulated.
  • Check now is on-demand, not continuous monitoring.
  • Always check official operator information before travel.
