## How Adhvaga uses it

- Dates inside 2024-08-12 to 2025-12-31: label **Timetable** (published, not proof it runs today).
- Any other date (all of 2026): the same weekday pattern, label **Estimated**, confidence low,
  reason "old timetable valid to 2025-12-31, pattern carried forward".
- Fares: label **Estimated** (KMRL fare chart in the feed, Aug 2024).
- Never **Live**: KMRL publishes no live feed.
